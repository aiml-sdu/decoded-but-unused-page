# Decoded but Unused: project page

Project page for *Decoded but Unused: Instruction Tuning Routes Moral Framing into the Judgment Readout* (Phongsakon Mark Konrad, Toygar Tanyel, Serkan Ayvaz; ICML 2026 Workshop on Mechanistic Interpretability), served at https://aiml-sdu.github.io/decoded-but-unused-page/.

This repository holds the built static page only, a single `index.html`. Every plotted value is read from the paper's stored figure data or its tables. The code and data will be released at https://github.com/aiml-sdu/decoded-but-unused.
